Логическое правило, схема и состояние

В цифровой схеме напряжение на проводнике представляет логическое значение. Логический уровень 0 или 1 обозначает диапазон допустимых напряжений. Таблица истинности показывает, какой выход требуется при каждой комбинации входных значений.

Дальше различают два случая. У комбинационной схемы результат зависит от текущих входов. Последовательностная схема также учитывает сохранённое состояние. Это различие видно при сравнении сумматора и счётчика: сумматор выдаёт новое значение, а регистр удерживает его до следующего изменения.

Зачем процессору логические элементы

Логическая переменная принимает одно из двух значений, условно обозначаемых нулём и единицей. В электронной схеме этим значениям соответствуют допустимые диапазоны напряжения. Физический сигнал не обязан быть ровно равен нулю вольт или некоторому единственному напряжению единицы. Между диапазонами предусматривается запас, позволяющий отличать полезное состояние от небольших помех. Значения вне установленных границ не следует трактовать как дополнительную логическую цифру.

Логический элемент реализует булеву функцию. Его поведение можно описать таблицей истинности, в которой перечислены все допустимые сочетания входов и соответствующие выходы. Для двух входов существует четыре сочетания, для трёх — восемь. Таблица не описывает конкретную конструкцию транзисторов, но полностью задаёт логическое назначение элемента. Это позволяет сначала рассуждать о правильности функции, а затем выбирать её физическую реализацию. Процессор строится из большого числа таких элементов, объединённых в вычислительные и управляющие схемы.

Схему из логических элементов можно исследовать последовательно, вычисляя выходы промежуточных узлов. Если сначала выполняется AND, а затем инверсия, получается NAND. При двух единичных входах AND выдаёт единицу, после инверсии получается нуль. Для остальных сочетаний результат NAND равен единице. Такое описание отделяет логическую функцию от названий конкретных электронных компонентов.

Зачем при сложении нужен перенос

При сложении в столбик результат одной позиции может не поместиться в ней. В двоичной системе это происходит уже при 1 + 1: результат записывается как 10. Младший разряд суммы равен 0, а в следующий разряд нужно передать 1. Эту единицу называют переносом.

Схема, которая складывает два входных бита и выдаёт сумму и перенос, называется полусумматором. Для суммы требуется элемент XOR (исключающее ИЛИ): единица появляется, если входы различаются. Для переноса требуется И, потому что перенос появляется, только когда оба входа равны единице. Эти два выхода отвечают на разные вопросы о результате сложения.

В следующем разряде нужно сложить уже три бита — два бита исходных чисел и перенос от предыдущего разряда. Эту задачу решает полный сумматор. Например, при входах 0, 1 и 1 выход суммы равен 0, а выход переноса — 1. Соединяя выход переноса одного полного сумматора со входом следующего, можно сложить многобитные числа.

Как из битов получается сложение

Сложение двоичных чисел выполняется поразрядно с учётом переноса. Для сложения двух одноразрядных чисел полусумматор формирует два выхода. Бит суммы определяется операцией XOR, перенос — операцией AND. При входах 1 и 1 сумма равна нулю, а перенос равен единице, поскольку десятичное число 2 записывается как 10₂.

В многозначном сложении на очередной разряд поступает также перенос из предыдущего. Поэтому требуется полный сумматор с тремя входами. Если единица присутствует на одном или трёх входах, бит суммы равен единице; перенос возникает, когда единичны хотя бы два входа. Последовательное соединение полных сумматоров образует многоразрядный сумматор. Однако результат старших разрядов может зависеть от распространения переноса через младшие. Такая зависимость создаёт задержку. Более сложные схемы ускоряют вычисление переносов ценой дополнительных элементов. Уже на этом простом примере виден общий компромисс между быстродействием, площадью и сложностью устройства.

Перенос за пределы старшего разряда и знаковое переполнение необходимо различать. При четырёхразрядном беззнаковом сложении 1111 + 0001 результат требует пятого разряда. При знаковом сложении 0111 + 0001 получается 1000, то есть вместо положительного результата возникает отрицательная интерпретация. Оба случая ограничены разрядностью, но обнаруживаются по разным признакам.

Полный сумматор получает A = 1, B = 0 и входной перенос C = 1. Всего присутствуют две единицы, поэтому результат равен 10₂: бит суммы равен 0, выходной перенос — 1. Следующий разряд должен учитывать этот перенос. Если в четырёхразрядном сложении 0011 + 0001 обработать младшие разряды последовательно, результатом будет 0100. После установления сигналов регистр результата принимает 0100 на предусмотренном тактовом фронте, если разрешена запись. Сумматор вычисляет, а регистр сохраняет.

Из главы Харрисов о функциональных узлах можно вывести оценку для сумматора с последовательным переносом. Если перенос через одну ступень занимает 450 пс, то в простой модели перенос через 64 ступени займёт 28 800 пс, то есть 28,8 нс. Быстрые сумматоры уменьшают ожидание, вычисляя часть переносов заранее.

Как направить к сумматору нужные данные

Вычислительный узел может использоваться для разных действий. Например, в один момент сумматору нужны два значения из регистров, а в другой — значение регистра и постоянная единица. Чтобы обойтись одним сумматором, перед его входом ставят схему выбора — мультиплексор.

У мультиплексора на два источника есть два входа данных и один управляющий вход. При значении управления 0 на выход проходит первый источник, при 1 — второй. Если складываются четырёхразрядные числа, правило выбора применяется сразу к четырём разрядам. На выходе должна появиться целиком выбранная группа битов.

В учебном счётчике один источник может выдавать прежнее число, а другой — вычисленное значение плюс один. Управляющий сигнал определит, какое из двух чисел нужно передать на запись. Чтобы счётчик мог выполнить следующий шаг, схеме требуется место, где сохраняется текущее число.

Мультиплексор и управление данными

Вычислитель должен не только получать результаты, но и выбирать источники данных. Мультиплексор представляет собой управляемый переключатель сигналов. В варианте с двумя входами данных один управляющий бит определяет, какой из входов соединяется с выходом. Он не складывает значения и не запоминает их. Для передачи многобитного слова параллельно используют одинаковый выбор для всех его разрядов.

Пусть на первый вход подано значение регистра, а на второй — константа из команды. При одном состоянии управляющего сигнала арифметическое устройство получает содержимое регистра, при другом — константу. Такая схема позволяет одному вычислительному блоку участвовать в выполнении разных команд. Дешифратор решает другую задачу: по двоичному входному коду активирует выбранный выход. Например, он может сформировать разрешение записи в один из регистров. Управляющие схемы организуют движение данных, поэтому правильного арифметического результата недостаточно, если он записан не в тот регистр или не в тот момент.

Для выбора одного из четырёх источников мультиплексору необходимы два управляющих бита: они дают четыре комбинации. Для восьми источников нужны три бита. Это прямое следствие числа возможных двоичных кодов. Значение выбранного источника передаётся на выход, а остальные источники не должны одновременно управлять тем же выходным сигналом.

Из сумматора, побитовых схем и мультиплексора можно собрать учебное арифметико-логическое устройство. На его входы поступают два слова данных и код операции. Сумматор вычисляет сумму, а логические схемы формируют результаты AND, OR и XOR. Мультиплексор выбирает одно из этих значений по коду операции. Код задаёт режим работы, а данные определяют результат выбранного действия. Результат остаётся на выходе схемы, пока сохраняются её входы. Для хранения его записывают в регистр отдельным действием.

АЛУ может вместе с результатом выдавать признаки. Признак нуля показывает, что все биты результата равны нулю. Перенос из старшего разряда связан с выходом за диапазон беззнакового числа при сложении. Знаковое переполнение определяется правилами дополнительного кода. При сложении двух чисел одного знака оно возникает, когда усечённый результат получает противоположный знак. Набор признаков, доступных программе, зависит от системы команд. При сравнении схема может использовать вычитание для получения признаков, не сохраняя саму разность в регистре данных.

У мультиплексора с четырьмя входами два управляющих бита. Их комбинации 00, 01, 10 и 11 выбирают один вход из четырёх. Если на входах находятся слова, на выходе появляется всё выбранное слово. Регистр, подключённый к этому выходу, может сохранить слово по тактовому сигналу. Мультиплексор выбирает источник, а регистр удерживает результат.

Как схема удерживает результат между шагами

Сумматор реагирует на текущие входы. Стоит изменить входное число, и через небольшое время изменится выход. Для счётчика этого недостаточно: после вычисления нужно удержать новое число и подать его на сумматор на следующем шаге. Эту роль выполняет регистр.

В модели с тактовым сигналом регистр принимает новое значение в определённый момент, например при переходе сигнала из нуля в единицу. До следующего разрешённого обновления его выход показывает прежнее записанное значение. Поэтому можно отдельно проследить, что схема уже хранит и что она только собирается сохранить.

Пусть регистр содержит 3, а режим счётчика требует прибавить 1. Сумматор вычисляет 4, но выход регистра до обновления остаётся равным 3. В момент записи он меняется на 4. Теперь 4 становится входом следующего вычисления. Соединение регистра, сумматора и схемы выбора даёт полный путь от одного состояния счётчика к следующему.

Почему компьютеру нужна память состояния

Комбинационная схема формирует выход на основании текущих входов и после прохождения задержек не хранит историю вычислений. Для последовательного выполнения программы требуется состояние, сохраняющееся между шагами. Его удерживают элементы памяти, из которых строят регистры. Регистр из восьми разрядов хранит восьмибитное слово; каждый разряд отвечает за один бит, а общие сигналы управления согласуют обновление всего слова.

В синхронной модели запись обычно связывается с определённым фронтом тактового сигнала. Между фронтами комбинационная схема вычисляет новое значение, а на следующем разрешённом фронте регистр его принимает. Так разделяют текущее и следующее состояние. Тактовый период должен учитывать время вычисления и требования регистров к стабильности входов. Слишком ранняя запись может зафиксировать неустановившийся результат. Поэтому увеличение частоты ограничено задержками схемы и физическими условиями. Такт не является универсальной мерой одной законченной команды: команда может занимать несколько стадий, а разные команды могут обрабатываться одновременно.

Если выход регистра возвращён на вход вычислительной схемы, на каждом такте можно получать новое состояние из предыдущего. Например, сумматор прибавляет единицу к сохранённому значению, после чего регистр принимает результат. Так строится счётчик. Наличие обратной связи само по себе недостаточно: требуется правильно организовать хранение, разрешение записи и временные условия.

Между двумя регистрами сигнал проходит через комбинационные элементы с конечной задержкой. Самый долгий путь, влияющий на принимаемый результат, называется критическим. К моменту записи принимающий регистр должен получить устойчивое значение. Поэтому период тактового сигнала выбирают с учётом задержки пути, выхода передающего регистра и времени, нужного принимающему регистру до тактового фронта. Частота ограничена реальным временем распространения сигнала.

Если разделить длинную цепь вычислений дополнительным регистром, каждая часть может укладываться в более короткий такт. Один результат при этом проходит больше тактов, зато следующие данные можно принимать чаще. Различие между временем прохождения одного результата и частотой выдачи результатов лежит в основе конвейера.

Пошаговый разбор полного сумматора и регистра результата

Построим полный сумматор, не начиная с готовой схемы. У него три входа — A, B и входной перенос C. Результат выражается суммой S и выходным переносом K. Для комбинации 000 нужно выдать 00. Для 001, 010 и 100 сумма равна одному, поэтому выход 01. Для 011, 101 и 110 сумма равна двум, поэтому выход 10. Для 111 сумма равна трём, поэтому выход 11. Так восемь строк таблицы покрывают все входы.

Заметим закономерность. S равен единице при нечётном числе единиц на входах, поэтому его можно получить последовательным XOR. K равен единице, если единиц не меньше двух. Его можно выразить через три попарных AND и объединяющий OR. Другой вариант — два полусумматора. Сначала складываются A и B, затем промежуточная сумма и C. Переносы объединяются. Разные схемы могут реализовывать одну таблицу истинности.

Соединим четыре таких блока и сложим 1011 и 0110. В младшем разряде 1 + 0 даёт сумму 1 без переноса. Далее 1 + 1 даёт 0 с переносом 1. Следующий разряд получает 0 + 1 + 1 и снова выдаёт 0 с переносом. Последний обрабатывает 1 + 0 + 1 и даёт 0 с выходным переносом. Полный результат — 10001. Если регистр результата имеет четыре бита, он удержит только 0001.

Этот опыт связывает переполнение с физической шириной схемы. Сумматор не обязан «ошибаться», когда программа выбрала слишком узкий формат. Он может корректно выдать младшие разряды и отдельный признак переноса. Интерпретировать эти сведения должна программа или управляющая логика. Для знаковых чисел условие переполнения отличается от простого наличия выходного переноса.

Наконец, добавим регистр. Пока входы меняются, комбинационный результат может ещё переходить между состояниями. Регистру разрешают принять новое значение только при соблюдении условий синхронизации. Если требуется режим «сохранить», мультиплексор выбирает старый выход регистра вместо новой суммы. Теперь одни и те же узлы могут образовать счётчик. Вычисление, выбор и хранение становятся тремя различимыми функциями, которые дальше встретятся внутри CPU.
